# Suggested Commands

- Install: `npm install`
- Development server (Vite, default port 5173): `npm run dev`
- Run tests in watch mode: `npm test`
- Run tests once: `npm test -- --run`
- Type-check and production build: `npm run build`
- Preview production build: `npm run preview`
- Validate Serena memory references: `serena memories check`
- Rebuild Serena project index if required: `serena project index` from repository root.
